# Seaborn---Supermarket-Dataset
Supermarket Sales dataset-i pərakəndə satış şəbəkəsinin əməliyyatlarını və müştəri davranışlarını analiz etmək üçün istifadə olunan məşhur datasetdir. Məlumatlar filiallar, məhsul kateqoriyaları, qiymət, ödəniş üsulları, müştəri tipləri və qiymətləndirmə (rating) göstəricilərini əhatə edir. Satış proqnozu və ehtiyatların idarə edilməsi.
